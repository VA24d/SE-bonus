# Software Carbon Intensity (SCI) Specification

**Standard Code:** ISO/IEC 21031:2024
**Authoring Body:** Green Software Foundation

## Verification
The SCI standard is openly available as a formal specification online rather than a traditional academic PDF. The mathematical equation $SCI = \frac{(E \times I) + M}{R}$ and its core variables have been verified against the official specification. 

It can be accessed in its entirety here:
[https://greensoftware.foundation/sci]
